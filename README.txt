HOW TO PLAY
1. Extract the ZIP file into a folder.
2. Keep index.html and chapter1.html through chapter5.html together in that folder. The README and test report are documentation.
3. Open index.html in a modern web browser.
4. Choose a chapter and use the command box. Type HELP inside a chapter for instructions.

CHAPTER FOUR COMMANDS
LOOK, GO [direction], TAKE [item], USE [item], TALK, INVENTORY, READ,
MAP, SAVE, LOAD, RESTART, HELP.

Chapter Four puzzle route:
- Go DOWN from the Root Stair to the Flooded Gallery and TAKE the brass key.
- Go EAST to the Machine Chapel; TAKE the copper wire and USE the brass key.
- Go NORTH to the Memory Kiln; TAKE the glass lens and sleeping ember.
- USE the glass lens to read the smoke; USE the sleeping ember to awaken it.
- Go EAST to the Underlake. USE the copper wire, then the glass lens, then the awakened ember.
- Go DOWN to the Root Engine, then EAST to the Split Chamber.
- Choose MEND, OPEN, or BIND.

SAVES AND PRIVACY
Each chapter uses its own browser-local save. No account, subscription, paid service,
external API, external library, or network connection is required. Save availability
can vary by browser privacy settings. Use the same browser and avoid clearing its
site data if you want to keep your progress.

The archive launcher does not automatically transfer story choices between chapters.


CHAPTER FIVE — THE SILENCE AFTER
Commands: LOOK, GO [direction], TAKE [item], TALK, INVENTORY, MAP,
CHOOSE [MEND/OPEN/BIND/REMEMBER], SAVE, LOAD, RESTART, HELP.

Explore the Quiet Platform, Unrooted Garden, Empty Observatory, and Last Archive.
To discover the hidden REMEMBER ending, take the paper bird, music box, clear lens,
and blank book; TALK in the garden and observatory; then choose REMEMBER at the archive.
The MEND, OPEN, and BIND epilogues can be selected directly at the Last Archive.
Chapter Five is self-contained and does not automatically read Chapter Four's save.
